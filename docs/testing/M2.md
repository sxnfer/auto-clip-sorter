# M2 manual test checklist: recordings, screenshots and the save sound

**What M2 delivers:**
- **Recordings** are sorted into `<Clips folder>\<Game>\…` when you stop recording, including every part of a split recording and the `.mp4` that auto-remux makes.
- **Screenshots** taken in OBS are sorted the same way.
- The settings dialog has a **What to sort** section (replays, recordings, screenshots) and an optional **Save sound** that plays when a replay has been saved.
- Replays still work as in M1. Their code now runs through the same filing code as recordings, so steps 1–4 re-check them.

**You need:**
- Windows 10 or 11, OBS Studio 31 or newer, and one game you can start and quit quickly (Counter-Strike 2 is fine).
- The Windows zip from the M2 pull request (see **Download** below).
- The Replay Buffer turned on, as in M1.
- For the sound steps: any short `.wav` file. Windows has some in `C:\Windows\Media`, for example `C:\Windows\Media\Windows Notify System Generic.wav`.

Write **Pass** or **Fail** in each Result cell. If something fails, open **Help → Log Files → View Current Log**, search for `clip-atlas`, and paste the nearby lines into Notes.

## Download and install

1. Open the Actions run linked in the pull request (or in my message). You must be signed in to GitHub.
2. Scroll to the bottom of the page, to **Artifacts**.
3. Click the one whose name ends in **`windows-x64-<commit>`**. A zip file downloads.
4. Close OBS.
5. Unzip the download. Inside is a second zip; unzip that too.
6. Delete the old `C:\ProgramData\obs-studio\plugins\clip-atlas` folder.
7. Copy the new `clip-atlas` folder into `C:\ProgramData\obs-studio\plugins\`. Windows asks for administrator permission; allow it.

## Steps

| # | Step | Expected result | Result | Notes |
|---|---|---|---|---|
| 1 | Start OBS. Open **Help → Log Files → View Current Log** and search for `clip-atlas`. | `[clip-atlas] loaded v0.1.0` and the clips folder line. No errors. | | |
| 2 | Open **Tools → Clip Atlas Settings…**. | Four sections: **Clips**, **What to sort** (Replays, Recordings, Screenshots all ticked, and "File each recording under the game played longest" not ticked), **Replay Buffer**, and **Save sound** (off; the file, volume and Test controls are greyed out). Your M1 settings are still there. It matches your OBS theme. | | |
| 3 | Close the dialog. Start your game. Save a replay. | The replay goes to `D:\Clips\<Game>\` as in M1. | | |
| 4 | (If you use auto-remux.) Save another replay. | Both the `.mkv` and the `.mp4` end up in the game folder, as in M1. | | |
| 5 | With the game running, click **Start Recording**. Record about 15 seconds, then click **Stop Recording**. Wait about 10 seconds. | The recording is in the game folder, not in OBS's recording folder. With auto-remux on, the `.mkv` and the `.mp4` are both there and the `.mp4` plays. | | |
| 6 | With **no** game running, record 10 seconds and stop. | The recording goes to `D:\Clips\Unsorted\`. | | |
| 7 | Start a recording while the game runs, quit the game during the recording, then stop it. | The recording goes to the **game's** folder (by default the game is chosen when the recording starts). | | |
| 8 | Split recording: in **Settings → Output → Recording** (switch Output Mode to **Advanced** if needed), tick **Automatically split file**, choose **Split by Time**, 1 minute. With the game running, record about 2½ minutes, then stop. Wait about 15 seconds. | All 3 parts (and their `.mp4` copies if auto-remux is on) are in the game folder. None are left in the recording folder. Put the split setting back afterwards if you don't want it. | | |
| 9 | Press OBS's **Screenshot** hotkey (set one in **Settings → Hotkeys → Screenshot Output** if you have none) while the game runs. | The `.png` goes to the game folder. | | |
| 10 | Take a screenshot with no game running. | The `.png` goes to `D:\Clips\Unsorted\`. | | |
| 11 | Open the settings, untick **Screenshots**, click OK, and take a screenshot. | The screenshot stays where OBS saved it (your recording folder). Tick it again afterwards. | | |
| 12 | Untick **Recordings**, click OK, record 10 seconds during a game and stop. | The recording stays in OBS's recording folder. The "game played longest" box was greyed out while Recordings was unticked. Tick Recordings again afterwards. | | |
| 13 | Tick **File each recording under the game played longest** and click OK. Start a recording with **no** game, wait 20 seconds, start the game and keep it running for about 1 minute, then stop the recording. | The recording goes to the **game's** folder (time with no game doesn't count). | | |
| 14 | Untick the "game played longest" box again. In **Save sound**, tick **Play a sound when a replay is saved**. Click **Test** with the file field empty. | A message asks you to choose a `.wav` file first. | | |
| 15 | Click **Browse…**, choose a `.wav` (e.g. from `C:\Windows\Media`), and click **Test**. Move the volume slider down to about 30 and click **Test** again. | You hear the sound; the second time it's clearly quieter. | | |
| 16 | Click **OK**. With the game running, save a replay. | After a moment you hear the sound **once** (also once with auto-remux on, even though two files move). | | |
| 17 | Record and stop a recording, and take a screenshot. | No sound for either: the sound is only for replays. | | |
| 18 | (Optional) Watch the Desktop Audio meter in OBS's mixer while you click **Test**. | The meter moves: this is why the help text warns that viewers and later clips can hear the sound. | | |
| 19 | Untick **Play a sound when a replay is saved**, click OK, and save a replay. | No sound. | | |
| 20 | Close OBS while a recording is running (OBS asks you to confirm). Start OBS again. Repeat with nothing running. | OBS closes and starts cleanly, with no crash and no "not responding". The interrupted recording may be left in OBS's recording folder; that is expected. | | |
| 21 | Close OBS and start it again. Open the settings. | Every setting you changed (What to sort, sound file, volume) is still there. | | |
| 22 | Look through the log for lines with `clip-atlas`. | Every sorted file has an INFO line with its final path. No WARNING or ERROR lines, apart from any you caused on purpose. | | |
