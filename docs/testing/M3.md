# M3 manual test checklist: the Clip Atlas dock

**What M3 delivers:** a **Clip Atlas** panel inside OBS (a "dock") that shows:
- the game Clip Atlas sees right now, whether the Replay Buffer is running, and an **Auto-sort** switch;
- notices when something needs fixing (no clips folder, folder missing, Replay Buffer turned off);
- your clips, newest first, with a preview picture, the game, how long ago, and the size;
- a game filter and a search box;
- a right-click menu on each clip: **Open**, **Show in folder**, **Rename…**, **Move to game…**,
  **Move to Recycle Bin…**;
- buttons at the bottom: **Open clips folder**, refresh (⟳) and settings (⚙).

**You need:**
- Windows 10 or 11, OBS Studio 31 or newer, and one game you can start and quit quickly.
- The Windows zip from the pull request (see **Download and install** in `docs/testing/M2.md`; the steps are the
  same).
- Some clips already sorted by M1/M2 in your clips folder (`D:\Clips` for you).

Write **Pass** or **Fail** in each Result cell. If something fails, open **Help → Log Files → View Current Log**,
search for `clip-atlas`, and paste the nearby lines into Notes.

## Steps

| # | Step | Expected result | Result | Notes |
|---|---|---|---|---|
| 1 | Start OBS. Open the **Docks** menu. | It has a **Clip Atlas** entry. | | |
| 2 | Click **Docks → Clip Atlas**. | A panel called **Clip Atlas** opens (it may float at first). It matches your OBS theme: no odd colours, readable text. | | |
| 3 | Drag the panel next to your other docks so it docks there. Close OBS and start it again. | The panel comes back in the same place. | | |
| 4 | Look at the list. | Your existing clips are listed, newest first. Each row shows a preview picture (or a file icon while it loads), the file name, the game folder, "… ago", and the size. Replays say **Replay** on the right, recordings **Recording**, screenshots **Screenshot**. | | |
| 5 | With no game running, look at the top of the panel. | It says **No game detected** and shows the Replay Buffer state (for example **Replay Buffer stopped**). | | |
| 6 | Start your game. | Within a few seconds the top shows the game's name, and (with auto start on) **Replay Buffer on (started by Clip Atlas)**. | | |
| 7 | Save a replay. | A few seconds later the new replay appears at the top of the list, under the game's name, "just now". | | |
| 8 | Take a screenshot and record 10 seconds. | Both appear at the top of the list once they are sorted. | | |
| 9 | Pick your game in the **All games** drop-down. | Only that game's clips are listed. Pick **All games** again. | | |
| 10 | Type part of a clip's name in **Search clips**. Then type something that matches nothing, and clear the box with its ✕. | First only matching clips are listed; then the list is replaced by **No clips match.**; after clearing, every clip is back. | | |
| 11 | Double-click a video clip. | It opens in your video player. | | |
| 12 | Right-click a clip → **Show in folder**. | Explorer opens with that clip selected. | | |
| 13 | Right-click a clip → **Rename…**. Type a new name (without the extension) and click OK. | The file is renamed in Explorer and in the list. Its extension did not change. | | |
| 14 | Rename a clip to the name of another clip in the same folder. | A message says a file with that name already exists. Nothing changed on disk. | | |
| 15 | Rename a clip to `bad:name`. | A message says the name can't be used. Nothing changed. | | |
| 16 | Right-click a clip in **Unsorted** → **Move to game…**. Pick your game and click OK. | The clip moves into the game's folder (the month folder of when it was saved, if monthly folders are on). The list shows it under the game. | | |
| 17 | **Move to game…** again and type a new name, e.g. `Test Game`. | A `Test Game` folder is created and the clip moves there. Move it back afterwards. | | |
| 18 | Right-click a clip you don't need → **Move to Recycle Bin…**. Click **No**. | Nothing happens. | | |
| 19 | Do it again and click **Yes**. | The clip disappears from the list. Open the Windows **Recycle Bin**: it is there. Restore it if you like (then click ⟳ in the panel to list it again). | | |
| 20 | (Optional) On a USB stick or network drive with no Recycle Bin, put a test clip in a game folder under your clips folder, click ⟳, and **Move to Recycle Bin…** → **Yes**. | Windows asks whether to delete it permanently. Click **No**: the clip is still there. | | |
| 21 | Select a clip and press **F2**, then **Esc**. Select a clip and press **Delete**, then **No**. | F2 opens the rename box; Delete asks the Recycle Bin question. Nothing changes. | | |
| 22 | Click the **Auto-sort** switch off. Save a replay. | The replay stays in OBS's recording folder (not sorted). The switch stays off after restarting OBS. Turn it back on. | | |
| 23 | Click **⚙**. | The Clip Atlas settings open. | | |
| 24 | Click **Open clips folder**. | Explorer opens your clips folder. | | |
| 25 | In Explorer, delete or add a clip in a game folder, then click **⟳** in the panel. | The list matches the folder again. | | |
| 26 | In **OBS Settings → Output → Replay Buffer**, untick **Enable Replay Buffer** and click OK. | The panel shows a notice that the Replay Buffer is turned off in OBS. Tick it again: the notice goes away. | | |
| 27 | In Clip Atlas settings, set the clips folder to a folder that doesn't exist (e.g. on an unplugged USB drive) and click OK. | The panel shows a notice that the clips folder doesn't exist. Set it back to `D:\Clips`: the notice goes away and the clips come back. | | |
| 28 | Make the panel narrow, then wide. | Names shorten with "…" and the rows fit; nothing is cut off at the right, also when there is a scrollbar. | | |
| 29 | Close OBS while the panel is open and pictures are loading (click ⟳ just before closing). Start OBS again. | OBS closes and starts cleanly: no crash, no "not responding". | | |
| 30 | Look through the log for `clip-atlas`. | No ERROR lines. WARNING lines only for things you did on purpose (a rename to an existing name, a declined Recycle Bin question). | | |

## Known limits (expected, not failures)

- Files you change in Explorer show up in the panel after you click ⟳ (or when you switch profile or change the clips
  folder). Clips that Clip Atlas sorts appear on their own.
- Preview pictures come from Windows. A `.mkv` may show only a file icon if Windows has no thumbnail support for MKV on
  your PC; `.mp4` and `.png` usually show a picture.
- The panel lists at most the 5,000 newest clips.
- A remuxed replay or recording shows twice (the `.mkv` and the `.mp4`).
- The "old Python script is still loaded" notice comes with M4.
