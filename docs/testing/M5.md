# M5 manual test checklist: installer, update check and hotkey

**What M5 delivers:**
- A **Windows installer** (`clip-atlas-<version>-windows-x64-installer.exe`) next to the zip, with an uninstaller.
- An **update check**: once a day Clip Atlas asks GitHub whether a newer version has been published. If one has, a
  notice appears in the Clip Atlas dock with a **Download…** button that opens the release page in your browser.
  **Nothing is downloaded or installed automatically.** You can also check by hand with
  **Tools → Check for Clip Atlas Updates…**, and turn the daily check off in the settings.
- A **hotkey** to switch auto-sort on and off: **Toggle Clip Atlas auto-sort** in OBS's **Settings → Hotkeys**.
- An install guide (`docs/install.md`), a new README and a changelog.

**You need:** Windows 10 or 11, OBS Studio 31 or newer, and the Windows build from the pull request (see
**Download** below). Until a release has been published on GitHub, the update check can only say "no release yet";
steps 12–14 need a published release and can wait for it.

Write **Pass** or **Fail** in each Result cell. If something fails, open **Help → Log Files → View Current Log**,
search for `clip-atlas`, and paste the nearby lines into Notes.

## Download

1. Open the Actions run linked in the pull request (or in my message). You must be signed in to GitHub.
2. Scroll to **Artifacts** at the bottom and click the one ending in **`windows-x64-<commit>`**. A zip downloads.
3. Unzip it. Inside are two files: `clip-atlas-…-windows-x64.zip` (the manual install, as before) and
   `clip-atlas-…-windows-x64-installer.exe` (the installer).

## Known limits (expected, not failures)

- The installer is not code-signed, so Windows SmartScreen warns the first time (step 2).
- If you close OBS while an update check is talking to GitHub, closing can take up to about 30 seconds.
- Pre-releases (versions like `1.0.0-rc1`) are never offered by the update check; only published full releases.
- With no network, Clip Atlas tries again every hour and logs one WARNING each time.
